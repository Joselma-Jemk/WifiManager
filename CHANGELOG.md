# Changelog

## 0.1.0 (first public version)

- Hotspot control: state, start and stop, one-click new password with a Wi-Fi QR code.
- Connected devices with names you choose.
- Per-device blocking through the Windows Filtering Platform, applied by an administrator background service.
- Time-limited access (6, 12, 24 hours or custom), guest passes with a QR code, strict mode.
- Data usage: exact hotspot total, per-device share (estimated when several devices are connected).
- Keep alive: restarts the hotspot and the service, with a delay and an attempt limit.
- Modern interface with light and dark themes that follow Windows.
- Wi-Fi password kept with DPAPI.
- Fix: no console window flashes any more (every launched program is hidden).
